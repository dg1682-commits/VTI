# VTI Media Studio (올인원 웹 미디어 스튜디오)

파워쉘(터미널)이나 별도 프로그램 설치 없이 순수 웹 브라우저만으로 작동하는 **이미지 압축 · 이미지 변환 · 동영상 압축 · 유튜브 다운로드** 통합 웹 애플리케이션입니다.

---

## 📁 구성된 파일 목록
* `index.html` : 메인 웹페이지 화면 (더블클릭 시 크롬에서 즉시 실행 가능)
* `style.css` : 화이트(기본) & 다크모드 지원 반응형 디자인 스타일시트
* `app.js` : 이미지 압축/변환, 동영상 하드웨어 인코딩 압축, 유튜브 추출기 연동 스크립트

---

## 🚀 파워쉘 없이 깃허브(GitHub Pages)로 무료 웹사이트 띄우는 방법 (마우스로만 1분 완성)

1. 크롬에서 **깃허브(https://github.com)** 로그인 후 우측 상단 **`+` 버튼 → `New repository`** 클릭
2. **Repository name**에 원하는 이름(예: `vti-media`)을 적고, **Public** 선택 후 하단 **`Create repository`** 클릭
3. 생성된 화면에서 **`uploading an existing file`** 파란색 글씨 클릭
4. 내 PC의 `VTI` 폴더 안에 있는 **`index.html`, `style.css`, `app.js`** 파일 3개를 마우스로 드래그해서 끌어다 놓은 뒤, 아래 초록색 **`Commit changes`** 버튼 클릭
5. 상단 메뉴 중 **`Settings`(톱니바퀴)** → 좌측 메뉴에서 **`Pages`** 클릭
6. **Build and deployment** 아래의 **Branch** 항목에서 `None`을 **`main`**으로 바꾸고 **`Save`** 클릭
7. 약 1분 뒤 새로고침하면 상단에 **`https://내아이디.github.io/vti-media/`** 주소가 나타납니다! 이 주소로 접속하면 언제 어디서든 모든 기능을 사용할 수 있습니다.
